## 为什么要有它

⇒ ★ **实测：检索历史会话 ⇒ 0 条命中** ⇒ 那次讨论确实没被登记 ⇒ 我一直在重新发现、重新问。

⇒ ★★ **结论**：**开工前先读 `GOAL.md`**（那里有提炼过的目标与判据）；**原话本身按需从 git 里翻**。

## 体例（★ 三段式：微缩在前，全文在后）

```
## <主题>
- **微缩（10 秒可读）**：3–5 行结论。★ 默认只读这一段就够了。

```
