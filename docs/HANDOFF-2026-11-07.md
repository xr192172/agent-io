## §2 ★★ 用子代理的心得（这是本文件最值钱的部分）

### 2.1 第一轮只回报 —— 而它的价值 **90% 在"纠你"**，不在"执行"

今晚 11 个子代理，**每一个**都在第一轮纠了我至少一条，其中 5 个纠了 3 条以上。

**所以卡里必须写死的三问（照抄，别改）：**
```
① 卡里哪几条**与事实不符** —— 自己去核，别照抄
② 你要交的判据**有没有牙** —— 造一个「该红」的输入它确实红吗
③ 打算怎么做；卡在哪（**贴闸的原文**）
```

**★ 第一条要强调「别照抄」** —— 否则它会照着我写的错事实去干，而它本来能发现。

### 2.2 ★ 最反直觉的一条：**它造的"该红输入"可能不够狠，而你造的更不狠**

实例：T-39 那 2 条「次序」用例是我给的。它照做，然后**手工调换 C↔D 两个 if —— 没红**。
原因：我给的两条**各自只与 A 竞争**，互换 C 与 D 照不出来。
**它补了第 3 条（同时是 C 和 D 的输入）才红。**

```
⇒ 所以：**永远要求它「造一次该红并贴原文」**，而不是要求它「写一条判据」。
⇒ 而如果它说"造出来了"，追问一句：**「你试过把被测的东西改坏、看它真红吗？」**
```

### 2.3 每条判据要问「什么输入会让它红」—— 说不出来就是没牙

今晚验出没牙的判据有：
```
· 「调用点能被 find_references 找到」—— 测试里有 9 处调用 ⇒ **今天就是绿的**
· 「model 槽数 ≤ 23」—— 同时满足"什么都不做"和"做对了"
· 「断言 max_no_card === 1」—— 那是读数不是判据；真判据是「**删掉字段 ⇒ 红**」
```

### 2.4 ★ 要它在报告里写两节：「我不确定的地方」和「我没做的」

**这两节比交付值钱。** 实例：
- T-38 写「`resolveSlot` 调用方 = 0」—— 而它自己查出**测试里有 9 处**，真读数是「**生产写路径** 0 个消费者」
- T-40 写「17 条取法今天没有任何写路径在消费……**我没在这里冒充**」
- T-44 写「**如果读数从 7 变成 1，那就是我把它扫到地毯下了**」

**⇒ 一个诚实的人不是"不夸大"，是**在没人会检查的地方主动说「这条我没做到」**。**

### 2.5 ★ 它会自首 —— 而那是你要裁的，不是要罚的

T-45 写：「测试文件那条 `run` 判据**红了之后我改了它**（针写错编号）……这是本卡唯一一次"红了改判据"，请你复核。」

**⇒ 判法：改的是**指针**（指向一个从不存在的串）还是**内涵**？
   · 指针 ⇒ 修（恒红会被删掉，那比不写更坏）
   · 内涵 ⇒ 拒（那是放宽）
   ★ 而它顺手加了更强的针（`MUTATION_MARK`）⇒ **强度上升，认。**

### 2.6 卡里要抄进**当前** PITFALLS 条目号

今晚我抄了 P31–P39，它每次都因此避开了坑。
**但抄之前先 `grep` 确认那些条目真的在** —— 我今晚就抄错过（说 P31 实为 P30）。

### 2.7 不要让它在第一轮就落盘

**子代理没有"等审批"这个动作** —— 它会一口气做完。卡里写「第一轮只回报，然后结束本轮」，
第二轮用 `send_message` 放行。

### 2.8 ★ 给它权限说「你这句错了」

今晚 5 次它说我的卡里有一个**不存在的东西**（编造的引用 / 不存在的文件 / 不存在的卡 / 错了的行号 / 不成立的假设）。
**每一次都是本卡最重要的产出。**

⇒ 卡里明写：「**★ 今晚已被打回十几次，别照抄我**」—— 那句话是有效的。

### 2.9 那一问，它每次都答得比我的指标诚实

```
「我这轮让哪盏灯变绿了 —— 是修好了，还是它退出了检查范围？」
```
**⇒ 「修好了」和「它退出了检查范围」在读数上完全一样。只有这一问能分开它们。**
**⇒ 而它的变体更狠（T-44 给的）：**灯还亮着，但我**还数得出它亮几盏**吗？**数不出来 = 扫到地毯下了。**

### 2.10 派卡前的三条自量

```
· **先自己量分母** —— 别写"某处 N 条"，写"我在 X 文件里数到 N 条，命令是 Y"
· **匹配串 / 路径先 grep 确认逐字存在**（我今晚因此撞了 P31：`mustNot` 逐字空白敏感）
· **判据指向未来符号 ⇒ 卡领不到**（P32）；**表达式抛错 ⇒ 记 unsupported ⇒ 也领不到**（P38）
```

⑨ 判据指向未来符号 ⇒ 卡领不到（那不是红，是领不到）
