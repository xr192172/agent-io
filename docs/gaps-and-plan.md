⇒ **判断**：**"读"的那条路我们已经独立走通了；差的是"治理"**（版本 / 预算 / 准入 / 探针 / 面上锁）。
★ 而这五条**恰好治的都是我们自己的病**（下面 §二 会看到同型）——
所以"补治理"**不是学它，是补自己的洞**；它只是证明了这些洞在别的工程里也被认为是洞。
