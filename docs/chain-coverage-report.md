## 二、先分清两套完全不同的登记（★ 这是最容易混的地方）

| | 记什么 | 住哪 | 数量 |

| **工具面** | **能力**："我会干什么" | 工具注册表 | **69 个** |
| **Map（接棒表）** | **接力**："我产出的东西，怎么喂给下一个" | `src/domain/chain_wiring.ts` | **19 条边** |

★ 一条"接棒边"说人话就是：

> **`find_references` 找到的那批符号** →（挑第几个由你给）→ **填进 `rename_symbols` 的"改名清单"那一格**

⇒ 有了这条线，下一棒**不用猜字段名、不用数下标**。★ 没有这条线，就只能靠猜 —— 而**猜错不报错，只会静静地接错**。

### ★ 还有几个是"自己就是一条链"（不需要外接棒）
- `refactor_pipeline`（说明逐字："把可自动执行的瘦身改写**串成一条链，一次调用按序执行**"）

⇒ ★★ **所以"24 个"这个数字要打折** —— ★ **确凿的是那 8 个**，★ 另有一批是"自己就是链"、还有一批是说明里的字面误报 ✓

## 五、为什么值得治（不是洁癖）
