1. **派生条目会无声行使"要求权"** —— 加 derived `expected_apis` ⇒ drift 立刻从 clean 变 `missing_impl 2`（实测）。
   后果：门红时最省事的修法是"把设计册改回源码当前值" ⇒ 两者永远同源 ⇒ 设计册退化成纯镜像，**而它的绿是伪造的**。
   ⇒ 落成 `0.29⑥`（总判据：分歧时改哪一侧）+ 一张正在建的门（`75de0ef2`）。

2. **「什么算一条 API」曾有两把尺** —— `consistency.ts#actualApis` 只收 function/method，而设计侧扩到 const 函数形态
   ⇒ 一侧扩、另一侧没扩 ⇒ 假红。已收口到同一个 `isFunctionLikeSignature`（0.9.1）。

3. **`extractFuncName` 从 `const X = (a): Promise<B> =>` 里取到 `Promise`** 而不是符号名 —— 同上的第二层根因。

4. **`AGENTS.md` 21.2 KB 是 `ToolDef.description` 的第二份拷贝**（同一件事三个住处 = 0.9.1）⇒ 删表 + 退役 `gen_agents.mjs`。
