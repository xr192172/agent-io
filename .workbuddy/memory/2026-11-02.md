## §2 MCP 进程陈旧：一张卡收不了口的真因

```

⇒ 它一直用两天前载入内存的旧 dist 回答

```

★ 最该记的不是修好了，是**它怎么活到今天的**：`⚠️ STALE_BUILD` 这个警告**出现在每一次工具回执里**，
我把它当噪音忽略了一整天。⇒ 已写进 `AGENTS-RULES 0.7` 第四件：

> 出现 `STALE_BUILD` ⇒ 立刻二选一（kill server.js / 改用 CLI），**不许带着它继续出读数**。

一条从不触发动作的警告 = 一个没有的警告，甚至更坏：**它会把人训练成聋子。**
