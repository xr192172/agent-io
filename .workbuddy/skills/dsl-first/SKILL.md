# dsl-first —— 本仓的必学工具与必做动作

> ★★★ **为什么需要它**：**2026-10-15/16 一整天的"多轮迭代 / 边界漏了 / 报告与实际不符"，根因是同一个：**
> **agent 用 `grep` + `read` 去理解一个"专门为 agent 造的仓"，然后手工去补它本该有的护栏。**
> ★ 原话（用户）：*"我从最开始设计这个工具，就一直让你们自己用它 —— 但你每次都是直接用 grep，而不使用这个仓已有的便利工具。"*
> ★ 代价具体化：**① 没有护栏 ② 没有校验器 ③ 没有微缩（每次靠读全貌）④ 结论没有住处 ⑤ 每次从零。**

## 一、必学工具（★ 要干什么 → 用哪个）

| 要做什么 | ★ 用这个 | **不要** |
|---|---|---|
| 看项目全貌 / 结构 / 规模 / 层次 / 决策卡 | ★ **`get_dsl`**：`query=features \| nodes \| edges \| files \| decisions \| digest \| pending \| calls \| functions \| tag` | 读源码 |
| 理解"谁调谁 / 谁依赖谁" | ★ **`cache.db` 的 `edges`**（实测 call 7437 / type_ref 4727 / import 1202 —— **比 DSL 里的 1074 条丰富得多**） | grep 调用点 |
| 定位符号 / 校验"某处有没有某调用" | ★ **先查 DB `nodes`（8446 行）**；`grep` **兜底**，且**用时要标注"这是辅助"** | 一上来就 grep |
| 判断"能不能改" | ★ **`write_gate`**（`assertSourceWriteRegistered`：未登记不许落盘）· ★ **`validateDSL`**（图自洽） | 直接改 |
| 收账 | ★ **`npm run verify`（4 道门）** + **`certs/*.mjs`（每笔一枚证）** | "我觉得改好了" |
| 判"新旧 / 是否过期" | ★ **`_sync.scanRev` / `_sync.age`**（★ 没有它就会踩"读了 14.25h 前的实际"那个坑） | 凭印象 |
| 判"设计 vs 实际" | ★ **`diff_design_sheet`**（四类：同 id / 要实现 / 未纳入设计 / **认亲 `resolved`**） | 眼看 |

★ **实测对照（今天最有效的几笔，恰恰都是"用了工具"的）**：
§62 用 DSL 出全景（一次拿到 8 层 / 1074 边 / 决策卡 5 条）· §71 **DSL + DB 交叉**（抓到"决策卡说没闸、DB 说有"——**grep 读代码永远读不出来，因为两处各自都对**）·
§75/§76 **DSL 当讨论桌 + `validateDSL`**（逮住 guard 写反 + 我自己方案里的 2 条装饰边）。

## 二、必做动作（★ 三条）

1. ★★★ **开工前**：**先 `get_dsl` 取一次读数**（全貌 / 相关 query），**再动任何 `grep`**。
   ★ 判据：**说得出"我从 DSL/DB 拿到了哪几条读数"**；说不出 ⇒ **说明你还在用 grep 摸索**。
2. ★★★ **方案/结论**：**必须写成 DSL，并过 `validateDSL`**（★ 不是写成文档或聊天）。
   ★ 实测：一轮里**逮住 4 个肉眼看不见的错**（字符串裸引号 · `/type` 必须 `const` · `/version` 必须是字符串 · `/semantic/files` 必须是数组且 `id` 必须是**节点 id**）。
   ★★ **依据**：**"语言说得出、但判不了；DSL 一写，错自己就冒出来。"**（且可 diff：分歧写出来就是两张图）
   ★ 参考模板：`docs/task-system-plan.dsl.json`（用本仓 DSL 结构写的方案，含可判期望 + 状态机 + 巡检）。
3. ★★ **收账**：**每一笔都要有一条"用本仓工具取到的读数"**。
   ★ 判据：**"全绿 ≠ 被验"** —— ★ **新增一个方向（写端 / 新通路 / 新字段）⇒ 必须新增一条打它的证**；
   ★ **不许声称"没有行为改变"**（逐条列）；★ **留了残缺态 ⇒ 回退**（铁律：**半修比不修更坏**）。

## 三、元规矩

- ★★ **报告与实际不符，今天出现了 4 次**（子代理报"已修好"实际不符 / 只给回执 / 体检者推断过头 / 落盘后未生效）。
  ⇒ ★ **只信"自己跑出来的读数"**；★ **做/核分离**：一做一个核，**核者不读做者报告、只读盘上改动**。
- ★ **判新旧**：★ **"同一环境稳定" ≠ "跨环境稳定"**（实测：布局排序用 `localeCompare` ⇒ 换 locale 坐标全变）。
- ★ **真仓保护**：跑实验一律**临时目录 + 独立 `AGENT_IO_HOME`**；**真仓 `cache.db` 只读打开**（`readOnly:true`）。
- ★★ **完整清单**：`docs/preflight-checklist.md`（A 动手前 / B 做完后 / C 分工 / D 元纪律）—— ★ **每撞一个新洞就往里加一条。**
