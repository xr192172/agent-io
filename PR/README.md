# PR/ —— 外部需求与提案投递区

本目录用于**接收外部项目 / 使用者对 agent-io 的需求、改进提案、缺陷报告**。

与 `docs/` 的区别：

| | `docs/` | `PR/` |
|---|---|---|
| 内容 | **项目自己的**设计与规划文档 | **外部投递**进来的需求 / 提案 |
| 作者 | 本仓库开发者 | 任何使用者（含其它仓库的 agent） |
| 是否已采纳 | 已是项目共识 | **未定**，待评估 |

## 命名

`PR-<三位编号>-<短横线短名>.md`，例：`PR-001-duplicated-literal-table-detector.md`。

## 每份提案应当包含

1. **一句话**：要什么。
2. **现场**：提出方遇到的**真实**情况（要有可复现证据，不要设想）。
3. **需求**：要什么能力、判据是什么（**能不能红**）。
4. **为什么适合本项目**：接哪条已有的线 / 用哪个已有根基。
5. **验收**：提出方会怎么验（含**消融自证**与**假红对照**）。
6. **边界**：明说什么不做。
